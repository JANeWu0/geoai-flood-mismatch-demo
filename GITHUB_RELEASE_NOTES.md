# GitHub Release Notes

## Project purpose

This repository is designed as a public portfolio companion for the master's thesis:

Operationalizing Mismatch Diagnosis in Urban Flood Governance:
A Multimodal Vision–Language Framework for Dynamic Impact–Response Coordination.

## Design principles

The final structure combines:

1. Thesis methodology:
   - physical impact reconstruction;
   - LLM-assisted response visibility;
   - Spatial Mismatch Index;
   - signed residual diagnosis;
   - planning interpretation.

2. Portfolio demonstration:
   - runnable Python pipeline;
   - Streamlit dashboard;
   - Jupyter notebook workflow;
   - documented data assumptions.

## Important note

The included demonstration datasets are not the original confidential/research archives.
They reproduce the data structure and computational workflow.

Replace the demo inputs with verified research datasets when publishing empirical results.
